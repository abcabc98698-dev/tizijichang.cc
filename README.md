## 📖 项目简介 (Project Overview)

**梯子机场 (`tizijichang.cc`)** 是基于 **Astro 7** 与 **Starlight** 构建的新一代高性能、零膨胀纯静态网络评测中台。

不同于传统充斥广告弹窗与虚假宣传的 WordPress 机场博客或简陋导航站，本项目旨在用真实物理探针、结构化数据模型与严谨的测评方法论，为用户提供客观、中立、透明的跨境网络选型参考。

全站由 79 个纯静态 HTML 页面直出，无任何重型客户端运行时框架负担，首屏首次内容绘制 (FCP) 仅 **0.3 秒**，并在搜索引擎（Google、Bing、百度、神马）与生成式 AI 引擎（Perplexity、SearchGPT）中具备极佳的收录与答案抽取表现。

## 🚀 快速上手与本地开发 (Quick Start)

### 环境依赖
- **Node.js**: `>= 18.17.0` (推荐 Node.js 20 LTS 或更高版本)
- **包管理器**: `npm` / `pnpm`

### 本地启动
```bash
# 1. 克隆代码仓库
git clone https://github.com/abcabc98698-dev/tizijichang.cc.git
cd tizijichang.cc

# 2. 安装依赖包
npm install

# 3. 启动本地开发服务器
npm run dev
```

启动完成后，在浏览器打开终端输出的地址（默认为 `http://localhost:4321` 或 `http://localhost:4322`）即可体验完整站点。

## 🛠️ 构建与上线验收 (Build & Production)

```bash
# 生产环境静态打包（编译全站 HTML、生成 Pagefind 离线搜索索引与 sitemap.xml）
npm run build

# 本地预览打包产物
npm run preview
```

### 生产静态输出说明：
- 静态构建产物位于 `dist/` 目录；
- 包含自动生成的 `dist/sitemap.xml` 与 `dist/sitemap-index.xml`；
- 所有核心页面均编译为标准的绝对语义化路径（例如 `dist/vpn/index.html`）。

## 🌐 推荐部署方式 (Deployment)

### 选项 A：Cloudflare Pages（推荐）
1. 在 Cloudflare Pages 中连接本 GitHub 仓库；
2. 构建设置：
   - **Framework Preset**: `Astro`
   - **Build Command**: `npm run build`
   - **Build Output Directory**: `dist`
3. 绑定正式域名 `tizijichang.cc`。

### 选项 B：Vercel
1. 导入 GitHub 仓库；
2. 平台将自动识别并应用根目录的 `vercel.json` 规则；
3. 一键部署并配置自定义域名。
