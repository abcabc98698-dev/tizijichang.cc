代理协议是决定数据在客户端与境外服务器之间如何加密、打包与伪装的核心逻辑。随着防火长城 (GFW) 机器学习与主动探测算法的迭代，代理协议经历了一次次脱胎换骨的演进。

## 一、主流协议核心特性横向对比矩阵

| 协议名称 | 传输层基础 | 伪装与抗审查机制 | 握手延迟 | 恶劣网络提速能力 | 最佳适用场景 |
| :--- | :---: | :--- | :---: | :---: | :--- |
| **Shadowsocks (AEAD)** | TCP / UDP | 纯对称加密（无特征伪装） | 极低 (1-RTT) | 一般 | **IEPL / IPLC 物理专线内部首选** |
| **VLESS (Reality / Vision)** | TCP | 借用真实大厂证书伪装 TLS | 低 | 良好 | **公网抗封锁主力、综合全能王** |
| **Trojan** | TCP | 伪装成标准 HTTPS 网页流量 | 中等 | 良好 | 企业跨境办公、海外中转线路 |
| **Hysteria 2 (Hy2)** | **UDP (QUIC)** | 仿正常 QUIC 协议 + 端口跳跃 | **极低 (0-RTT)** | **极强 (抗 30% 丢包)** | **晚高峰恶劣网络、校园网/长城宽带** |
| **TUIC** | **UDP (QUIC)** | 原生 QUIC 0-RTT 握手 | 极低 | 优秀 | 移动设备快速重连、低延迟竞技 |

## 二、核心主流协议深度拆解

### 1. VLESS (Reality) —— 2026 综合全能冠军
- **诞生背景**：过去的 VMess 协议包含复杂的时间戳校验和双重加密，导致 CPU 开销大、延迟高。VLESS 剥离了多余的加密层，作为轻量级数据管道。
- **Reality 绝技**：传统的 TLS 伪装需要机场自己购买域名和配置 SSL 证书，这极易被针对性阻断。**Reality 技术**允许直接借用第三方海外顶级大厂（如 Apple、Microsoft、Amazon）的真实证书。审查者进行主动探测时，看到的完全是合法的苹果或微软官方服务器应答，抗封锁能力拉满。

### 2. Hysteria 2 (Hy2) —— 暴力提速与抗丢包神器
- **底层原理**：基于魔改的 UDP QUIC 协议，内置专有拥塞控制算法。
- **核心优势**：在普通 TCP 连接遇到 10% 丢包就会发生窗口断崖下跌（速度骤降 80%）的恶劣网络环境下，Hy2 依然能跑满本地物理带宽，秒开 4K/8K 视频。
- **潜在短板**：部分省份或特定运营商（如部分地区移动宽带）对大流量 UDP 数据包存在 QoS 惩罚性限速。

### 3. Shadowsocks —— 专线场景下的不老常青树
- 许多用户误以为 Shadowsocks 已经过时。实际上在 **IEPL 物理专线** 内部，由于流量根本不暴露在公共公网出口，**无需任何复杂的伪装开销**。
- Shadowsocks 纯粹的高性能对称加密，反而是专线节点能跑出单节点 **2.5Gbps 超高带宽与极低 CPU 负载** 的最佳搭档。

## 三、机场选型时的协议搭配准则

1. **若购买物理专线机场（如 [#1 光速云](/brands/guangsuyun/)）**：
   - 优先选择 **VLESS** 或 **Shadowsocks** 协议，享受低时延与无损峰值吞吐。
2. **若购买平价中转机场**：
   - 确认其支持 **VLESS Reality** 或 **Hysteria 2**，以抵御晚高峰公网出口的抖动与丢包。
3. **客户端兼容性核对**：
   - 老版本软件可能不支持 Hysteria 2。建议统一使用现代化的 **Clash Verge Rev** 或 **Shadowrocket (最新版)**。
