## 二、使用 Clash Meta for Android (CMFA)

### 1. 下载与安装
从我们的 [客户端专区](/clients/) 下载 `Clash.Meta-xxx.apk` 并完成系统安全扫描与安装。

### 2. 导入通用订阅
1. 打开机场控制台（如 **[#1 光速云](/brands/guangsuyun/)**），点击「一键导入 Clash」或手动复制订阅 URL；
2. 打开 CMFA 应用，点击 **「配置」**；
3. 点击右上角 **「+」** 号，选择 **「从 URL 导入」**；
4. 填写名称（如 `光速云专线`），粘贴订阅链接，并在右上角点击「保存」按钮拉取节点；
5. 返回配置列表，勾选刚刚导入的配置文件。

### 3. 开启代理
1. 返回应用主界面，点击中央的 **「启动」** 按钮；
2. 首次启动会弹出系统标准的「网络连接请求 (VPN 提示)」，点击 **「确定」**；
3. 点击 **「代理」** 标签页，切换心仪的香港、日本、新加坡等节点。

## 三、安卓端核心避坑：开启后台防杀与电池优化

国内深度定制的安卓系统（小米 HyperOS、华为 HarmonyOS、vivo OriginOS、OPPO ColorOS 等）拥有极为严格的省电后台冻结机制，常导致“息屏后梯子立刻断开连接”。

### 解决三步法：
1. **锁定后台任务卡片**：从屏幕底部上划进入多任务后台，长按代理客户端卡片，点击 **小锁图标 (锁定)**；
2. **电池优化设为无限制**：进入系统 **「设置」 &rarr; 「应用管理」 &rarr; 选择该应用 &rarr; 「省电策略 / 耗电管理」**，将其调整为 **「无限制」** 或 **「允许后台高耗电」**；
3. **开启自启动权限**：在应用权限管理中，允许该软件的 **「后台自启动」** 与 **「关联启动」**。
